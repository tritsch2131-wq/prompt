PRD

바이브 코딩(Vibe Coding)이란?

코드를 직접 짜지 않고 AI에게 구체적인 요구사항(PRD)을 전달하여 앱을 제작하는 기법입니다.

1단계

해결하고자 하는 문제 정의하기

나쁜 예시 (너무 모호함) "학생들이 수업시간에 집중을 안 한다."
좋은 예시 (구체적 상황) "수학 시간에 딴짓을 하는 학생이 많다. 특히 대분수의 덧셈을 많이 힘들어한다."
2단계

타깃 사용자 및 사용 환경

누가, 언제, 어디서, 어떤 기기로 이 앱을 사용할 것인지 명확히 설정합니다.

3단계

해결방안 (한 문장으로 정의)

나쁜 예시 (추상적 목적) "재미있는 학습 앱을 만든다."
좋은 예시 (명확한 행동 및 가치) "학생들이 대분수의 덧셈 문제를 직접 풀어보고 피드백을 받을 수 있는 연습 앱을 만든다."
4단계

핵심 기능 정의 (MVP 설계)

최초 프로토타입에 꼭 필요한 필수 기능과 추후 고도화할 추가 기능을 분리합니다.

5단계

사용자 경험 (UX Flow 흐름 작성)

사용자가 앱을 처음 켜고 종료할 때까지의 이용 단계를 순서대로 적어주세요.
